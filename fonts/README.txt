Selbst gehostete Web-Schriften
==============================

Diese Verzeichnis enthaelt latin- und latin-ext-Subsets (woff2) der folgenden
Schriftfamilien. Beide stehen unter der SIL Open Font License, Version 1.1
(https://openfontlicense.org). Sie werden lokal ausgeliefert, damit beim Aufruf
der Website keine Verbindung zu Google Fonts o. ae. Drittanbietern entsteht.

- Inter            — (c) The Inter Project Authors (https://github.com/rsms/inter)
  inter-latin.woff2, inter-latin-ext.woff2

- JetBrains Mono   — (c) 2020 The JetBrains Mono Project Authors
  (https://github.com/JetBrains/JetBrainsMono)
  jetbrainsmono-latin.woff2, jetbrainsmono-latin-ext.woff2

Die woff2-Subsets stammen aus dem Google-Fonts-CSS-Endpoint (fonts.gstatic.com),
Achsenbereich als Variable Font. Zum Aktualisieren die vier Dateien neu ziehen
und ggf. die unicode-range-Angaben in den @font-face-Regeln der HTML-Seiten
abgleichen.
